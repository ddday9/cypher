# nevio для Android

Тот же клиент, что на Windows: серверы, ссылки `cypher://`, подписки,
маршрутизация geosite/geoip, свои правила, правила по приложениям, отпечаток,
одно соединение, защита от заморозки, ретранслятор со сквозным шифрованием,
логи. Отличия — в режимах (VPN Android вместо TUN и системного прокси) и в
разделе «Скрытность VPN».

Нужен Android 8.0 или новее.

## Установка

1. Скачайте `nevio-android.apk` со страницы
   [Releases](https://github.com/ddday9/cypher/releases/latest).
2. Откройте файл на телефоне. Android попросит разрешить установку из этого
   источника (браузера или файлового менеджера) — разрешите.
3. Запустите nevio → **Серверы** → вставьте ссылку `cypher://…` (кнопка
   «Из буфера») → **Добавить**.
4. **Главная** → большая кнопка. В первый раз Android спросит разрешение на
   VPN — разрешите. Первое подключение дольше: скачиваются базы geosite/geoip
   (~100 МБ, лучше по Wi-Fi).

Обновление — установите новый APK поверх, данные сохранятся (если релизы
подписаны одним ключом — см. [«Обновления»](#своя-сборка)).

## Режимы

| Режим | Что происходит | Когда выбирать |
|---|---|---|
| **VPN** (по умолчанию) | системный VPN Android; через cypher идут все приложения, кроме исключённых ([ниже](#скрытность-vpn)) | обычно |
| **Прокси (без VPN)** | VPN не включается вообще; nevio держит SOCKS5-прокси с паролем на случайном порту `127.0.0.1`. Через него идут только приложения, где прокси указан вручную | максимальная скрытность: для системы и других приложений VPN нет |

В режиме прокси на главном экране — адрес, логин и пароль и кнопка
**«Открыть в Telegram»**: Telegram сам предложит добавить прокси. В других
приложениях укажите SOCKS5 вручную. Чтобы Android не выгружал nevio в фоне,
в этом режиме работает фоновый сервис с тихим уведомлением «Работает в фоне».

## Настройки

Всё, что описано для Windows в [client.md, раздел 3](client.md#3-nevio-все-экраны-и-настройки),
работает так же, кроме системного прокси, портов и автозапуска Windows.
Только на Android:

### Скрытность VPN

| Настройка | Что делает |
|---|---|
| **Скрывать VPN от российских приложений** (вкл. по умолчанию) | около 60 приложений — Госуслуги, Госключ, Налоги, банки (Сбер, Т-Банк, ВТБ, Альфа и др.), маркетплейсы (Ozon, Wildberries, Avito), Яндекс, операторы, VK, OK, MAX, RuStore — идут **мимо VPN**. Список — по ссылке «Список» в настройках |
| **Через VPN идут** | «все приложения, кроме «Мимо VPN»» (по умолчанию) или «только выбранные приложения» — тогда в VPN попадают только приложения с действием «Через VPN», а все остальные его не видят |
| **Значок и название** | nevio, «Заметки» или «Калькулятор»: как приложение выглядит на рабочем столе |
| **Порт прокси** | порт для режима «Прокси (без VPN)»; логин и пароль создаются сами |

### Приложения

**Настройки → Приложения → «+ Добавить приложение»** — список установленных
приложений с поиском по названию и имени пакета. Действия:

* **Мимо VPN** — приложение работает без VPN: его трафик идёт напрямую, и
  для него VPN не включён. Используйте для банков и госприложений, которых
  нет во встроенном списке.
* **Через VPN** — нужно в режиме «только выбранные приложения».

### Постоянный VPN

Android может держать nevio включённым всегда: **Настройки Android → Сеть и
интернет → VPN → nevio (⚙) → Постоянная VPN**. Опцию **«Блокировать
соединения без VPN»** не включайте, если используете «Мимо VPN»: Android
может отрезать исключённые приложения от сети.

## Скрытность VPN

Задача — чтобы соседнее приложение (госприложение, банк, «шпион») не могло
понять, что VPN включён. Честно о том, что на Android без root возможно, а
что нет.

### Что видит приложение в зависимости от режима

| Способ проверки | Приложение **в** VPN | Приложение **мимо VPN** | Режим **Прокси (без VPN)** |
|---|---|---|---|
| Активная сеть (`ConnectivityManager`, флаг `TRANSPORT_VPN`) — самая частая проверка | видит VPN | **не видит** | **не видит** |
| Свой внешний IP (запрос к своему серверу) | IP сервера | **ваш обычный IP** | **ваш обычный IP** |
| DNS | через туннель | обычный DNS провайдера | обычный |
| Перебор **всех** сетей системы | видит | может увидеть, что VPN-сеть существует | **не видит** |
| Список сетевых интерфейсов (`tun0`) | видит | **видит** | **не видит** |
| Открытые порты на `127.0.0.1` | в режиме VPN у nevio портов нет | портов нет | порт есть, но случайный и с паролем |
| Список установленных приложений | может найти nevio (если у приложения есть доступ ко всем пакетам) | то же | то же |
| Значок ключа в строке состояния | виден **только вам**, приложения его не читают | — | ключа нет |

Что это значит:

* **Исключение «Мимо VPN»** закрывает самые распространённые проверки:
  флаг VPN у активной сети, внешний IP, DNS. Именно так проверяет
  большинство приложений.
* Приложение, которое **специально ищет** VPN (перебирает все сети и
  интерфейсы), на Android без root увидит интерфейс `tun0`. Имя интерфейса
  задаёт система, приложение не может его изменить или скрыть.
* **Полностью невидим только режим «Прокси (без VPN)»**: VPN в системе нет
  вообще. Цена — через прокси идут только приложения, где его можно указать
  (Telegram и некоторые другие).

### Что nevio делает для скрытности

* Встроенный список российских приложений — мимо VPN (включён по умолчанию).
* Никаких открытых портов в режиме VPN: интерфейс общается с ядром внутри
  приложения, без локального HTTP-сервера. Прокси (режим без VPN) — на
  случайном порту, с логином и паролем, на обычных портах 1080/10808 ничего
  нет.
* Без постоянного уведомления в режиме VPN; нейтральное имя VPN-сессии
  («Сеть») в настройках Android.
* Маскировка значка («Заметки», «Калькулятор»).
* Собственное имя пакета и название при сборке — [ниже](#своя-сборка).

### Рекомендации

1. **Банки и госприложения — мимо VPN** (встроенный список + свои в
   «Приложения»). Этого достаточно для большинства проверок.
2. **Рабочий профиль.** Поставьте госприложения и банки во второй профиль
   (Android «Рабочий профиль» через Shelter или Island, или «Личное
   пространство» в Android 15+). VPN основного профиля на них не
   распространяется, а **список приложений основного профиля им не виден** —
   они не найдут nevio. Интерфейс `tun0` всё равно виден системе целиком.
3. **Максимум скрытности** — режим «Прокси (без VPN)» для Telegram и т. п.,
   VPN не включать.
4. **Своя сборка с другим именем пакета**, если приложения начнут искать
   nevio по имени (`net.nevio.app`).
5. Перед запуском приложения, которое явно «ругается» на VPN, можно просто
   отключить nevio на время.

## Своя сборка

Нужны Go 1.26+, JDK 17, Android SDK и NDK r27, gomobile:

```bash
go install golang.org/x/mobile/cmd/gomobile@latest && gomobile init
```

```bash
make android ANDROID_APP_ID=com.example.notes ANDROID_APP_NAME="Заметки"
```

Получится `bin/nevio-android.apk` с вашим именем пакета и названием.
Подпись — [android/signing/README.md](../android/signing/README.md). APK с
другим именем пакета ставится как отдельное приложение; с другим ключом —
не ставится поверх (сначала удалите старое).

**Обновления.** Android ставит новую версию поверх старой, только если обе
подписаны одним ключом. Релизы подписываются ключом из секретов репозитория;
пока их нет, каждый релиз подписан временным ключом, и для обновления старую
версию придётся удалить (настройки и серверы при этом пропадут — сохраните
ссылки).

## Как это устроено

* Ядро — тот же Go-код, что на Windows и Linux (`mobile/`, собирается
  `gomobile bind` в AAR).
* Интерфейс — тот же, что у nevio на Windows, в WebView; запросы к ядру
  идут через мост JavaScript ↔ Kotlin внутри процесса.
* Режим VPN: `VpnService` создаёт интерфейс (IPv4 и IPv6, DNS внутри
  туннеля), передаёт его файловый дескриптор ядру; собственные соединения
  nevio исключены из VPN, поэтому не зацикливаются. Исключённые приложения
  передаются `VpnService` через `addDisallowedApplication`, выбранные — через
  `addAllowedApplication`.
* Режим прокси: SOCKS5 с аутентификацией (RFC 1929) на `127.0.0.1`.

## Ограничения

* ICMP (ping) через VPN не проходит.
* Правила по приложениям на Android работают на уровне VPN («мимо» или
  «через»); действия «Блокировать» для приложений нет.
* Приложение проверено сборкой, тестами ядра и работой интерфейса; на
  разных прошивках (MIUI, ColorOS и др.) могут понадобиться настройки
  энергосбережения: разрешите nevio работу в фоне.
* iOS — отдельный этап: нужен Mac, аккаунт разработчика Apple и Network
  Extension; App Store в России удаляет VPN-приложения по требованию РКН.
